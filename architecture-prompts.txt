LUXE — Architecture Diagram Image-Generation Prompts
=====================================================

Five prompts for an image generator (Midjourney / DALL-E / SDXL), one per
teaching diagram. Each prompt is self-contained — paste any one on its own.
Shared style: clean flat-vector architecture diagram, HD 4K, white background,
soft shadows, big simple icons, minimal short text labels (1-3 words per
node), no paragraphs, no code blocks.

If using Midjourney, append: --ar 16:9 --v 6 --style raw
For DALL-E / GPT image / SDXL-based tools, use the prompts as written.


1. Legacy System — 01-store-only
---------------------------------
Clean flat-vector tech architecture diagram, HD 4K, white background, soft
drop shadows, rounded-rectangle containers, blue-and-slate color palette, big
simple icons, minimal short text labels only (1-3 words per node), no
paragraphs, no code. Left-to-right flow: a browser/monitor icon labeled
"Customer" -> an arrow into a rounded container icon labeled "Storefront
(Vanilla JS)" showing small sub-icons for Home, Product, Cart, Profile, Admin
pages -> an arrow into a large gear/server icon labeled "FastAPI Backend"
containing small labeled module icons in a row: Auth, Products, Cart, Orders,
Admin -> a Google "G" logo icon feeding into the Auth module with a small
arrow -> the FastAPI icon connects via a thick arrow down into a
cylinder/database icon labeled "MongoDB Atlas" with four small labeled folder
icons beneath it: Products, Cart, Orders, Users -> the whole Storefront +
FastAPI box sits inside a large light cloud-shaped container labeled "Google
Cloud Run". Professional SaaS conference-keynote diagram aesthetic, plenty of
whitespace, big clear arrows showing direction of data flow.


2. MongoDB Schema & Data Flow
------------------------------
Clean flat-vector data-architecture diagram, HD 4K, white background, soft
shadows, blue-and-teal palette, big simple icons, extremely short text labels
only, no long sentences. Center-left: a large green leaf-logo database
cylinder labeled "MongoDB Atlas" with four small folder icons branching
below it, each with 2-3 short bullet labels: "Products (name, price, image)",
"Cart (user, product, qty)", "Orders (user, product, price)", "Users (email,
username)". From the Products folder, an arrow points right to a small
rounded card styled like a code/JSON snippet — large monospace text, only 5
short lines, keys like name, price, category, image — labeled "Raw Document".
A thick arrow from that card passes through a small gear/funnel icon labeled
"Transform" into a browser-window mockup on the far right showing a clean
product card with a photo, a name, and a price, labeled "Website". Flow reads
left to right: Database -> Raw JSON -> Transform -> Rendered UI. Big icons,
generous whitespace, minimal typography.


3. POC — Chatbot ReAct Agent
------------------------------
Clean flat-vector AI-architecture diagram, HD 4K, white background, soft
shadows, purple-and-blue palette, big simple icons, minimal short labels
only, no sentences. Left: a chat-bubble icon labeled "Customer" with an arrow
into a rounded rectangle labeled "Chat Widget". Arrow continues into a large
central robot/brain icon labeled "AI Agent". Around the agent, a circular
looping arrow with three short labeled steps evenly spaced on the loop:
"Think", "Act", "Observe". From the "Act" point on the loop, an arrow goes
down to a small magnifying-glass-over-database icon labeled "Search Tool",
which connects to a database cylinder labeled "MongoDB". A return arrow flows
from the agent back up through "Chat Widget" to a final chat-bubble icon
labeled "Response". Simple, uncluttered, generous whitespace, one clean loop
in the center, big icons, tiny text.


4. Secured Pipeline (Portkey + Guardrails + Observability)
-------------------------------------------------------------
Clean flat-vector AI-security-architecture diagram, HD 4K, white background,
soft shadows, purple-blue-and-amber palette, big simple icons, minimal short
labels only, no sentences. Left-to-right flow: chat-bubble icon labeled
"Customer" -> rounded rectangle "Chat Widget" -> a shield icon labeled "Input
Guardrail" -> a large central robot/brain icon labeled "AI Agent" with a small
circular loop icon on it (Think/Act/Observe, tiny labels) connected down to a
database cylinder labeled "MongoDB" via a magnifying-glass tool icon -> the
Agent also connects sideways through a funnel/gateway icon labeled "Portkey
Gateway" into a chip/brain icon labeled "LLM Model" -> back out of the Agent
through a second shield icon labeled "Output Guardrail" -> final chat-bubble
"Response" back to Customer. Above the entire pipeline, a horizontal band
with a small eye/graph icon labeled "Observability" has thin dotted arrows
tapping down into the Input Guardrail, the Agent, the Gateway, and the Output
Guardrail. Clear layered look: main flow on one horizontal line, monitoring
layer as a thin strip above it. Big icons, small clean text, generous
whitespace.


5. Full Integrated Architecture — main
-----------------------------------------
Clean flat-vector full-stack architecture diagram, HD 4K, white background,
soft shadows, blue-purple-slate palette, big simple icons, short labels only
(1-3 words), no sentences, no code blocks. Layered top-to-bottom layout with
four horizontal bands, each in a light rounded container labeled at its left
edge:
Band 1 "Client": a browser/monitor icon labeled "Storefront + Chat".
Band 2 "Application": a large rounded container labeled "FastAPI Backend"
holding small module icons in a row — Auth, Products, Cart, Orders, Admin,
Chat — with the Chat module icon connecting via an arrow into a compact
horizontal AI pipeline drawn as icons in sequence: shield ("Guardrail In") ->
funnel ("Portkey Gateway") -> robot/brain ("Agent") <-> chip ("LLM") -> shield
("Guardrail Out"), with the Agent icon also dropping a small arrow down to
the data layer.
Band 3 "Data": one large database cylinder labeled "MongoDB Atlas" with four
tiny folder icons beneath it — Products, Cart, Orders, Users — receiving
arrows from both the Application band's route modules and the Agent icon
above.
Band 4 "Platform": a cloud-shaped icon labeled "Google Cloud Run" and a small
eye/graph icon labeled "Observability & Evals" side by side, with thin
dotted arrows rising up into the Application band.
Clean vertical arrows connecting each band top to bottom, big icons,
generous whitespace, no clutter, professional system-design-diagram
aesthetic.
